# BeautyFinder Application

## Project Overview

BeautyFinder is a desktop application designed to help users discover beauty products based on their personal preferences. The system provides personalized product recommendations according to selected brands and budget range, making the product discovery process more efficient and user-friendly.

Users can view detailed product information such as product name, brand, price, rating, description, and category. The application also provides links to product and brand websites for additional reference.

In addition, users can save products into a wishlist and add personal notes to manage and evaluate potential purchases. Sorting and filtering features are included to help users compare products within their budget range.

The project was developed as part of an Object-Oriented Programming course to demonstrate the use of OOP principles in a real-world desktop application.

---

## Technologies Used

* Electron
* HTML
* CSS

## Features

* Product recommendation based on selected brand and budget
* Detailed product information display
* Product filtering and sorting by price
* Wishlist functionality with personal notes
* Links to external product and brand websites

## How to Run the Project

### 1. Clone the repository

```bash
git clone [repository-link]
```

### 2. Navigate to project folder

```bash
cd BeautyFinder
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```
